AGENDA ACADÉMICA

Aviso de Privacidad

Última actualización: 16 de noviembre de 2026.

1. Responsable y alcance

Angel Yael Saldaña Guzmán administra esta aplicación como proyecto académico en un entorno local de simulación. Este aviso describe el tratamiento de información dentro de esta práctica.

2. Información que se guarda

La aplicación guarda el texto de las tareas, su identificador, su estado de completado y su fecha de creación en una base de datos MySQL local.

Apache genera registros técnicos que pueden incluir dirección IP, fecha y hora, ruta solicitada, código de respuesta e información del navegador.

No se solicitan nombres, correos, contraseñas de usuario, datos bancarios ni datos sensibles. El texto de las tareas podría contener información personal si el usuario la escribe; para esta práctica deben utilizarse únicamente datos ficticios.

3. Finalidades

La información permite registrar, consultar, completar y eliminar tareas, así como comprobar la persistencia de datos. Los registros técnicos se utilizan para diagnosticar errores y verificar el funcionamiento del servidor.

4. Almacenamiento y protección

Los datos se almacenan en el equipo que ejecuta MySQL. El acceso mediante agenda.test utiliza HTTPS, encabezados de seguridad, validación de entradas y una cuenta de base de datos con permisos limitados.

La aplicación no cuenta con autenticación ni separación de tareas por usuario. Las personas que utilicen la aplicación en este equipo pueden consultar y modificar la misma lista. Estas medidas no garantizan protección absoluta frente a incidentes.

5. Conservación y eliminación

Las tareas permanecen hasta que se eliminan desde la interfaz o se retiran de la base de datos al finalizar la práctica. Eliminar una tarea no elimina los registros técnicos de Apache, que se administran por separado.

6. Comunicación de información

No se realizan transferencias intencionales de las tareas a servicios externos ni se utilizan para publicidad. Las evidencias académicas y el repositorio deben contener solamente datos de prueba, sin credenciales ni claves privadas.

7. Control de la información

El usuario puede consultar y eliminar tareas desde la interfaz. Para corregir su texto puede eliminar la tarea y crear otra. Las solicitudes relacionadas con información personal o registros técnicos deben dirigirse al responsable durante la práctica, quien deberá verificar la identidad antes de atenderlas.

8. Cookies y almacenamiento del navegador

Esta versión no implementa cookies de seguimiento ni utiliza localStorage para guardar tareas. Los datos de versiones anteriores que hayan quedado en localStorage pueden eliminarse desde la configuración del navegador.

9. Cambios al aviso

Las modificaciones se publicarán en esta página junto con su fecha de actualización.
